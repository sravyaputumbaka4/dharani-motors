# Dharani Motors Website

A fast, responsive, dependency-light static website for Dharani Motors.

## Run in VS Code
1. Extract/open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Replace the placeholder profile SVGs in `assets/images/` with the real partner/team photos. The header intentionally has a dedicated `LOGO` placeholder; replace that element with the Dharani Motors logo when you add the logo image.
4. In `index.html`, replace:
   - `Add your official business number here`
   - `Add your official business email here`
   - `YOUR-BUSINESS-EMAIL@example.com`
5. Review all business figures/locations before publishing.

## GitHub Pages
Push the folder to a GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save. GitHub Pages publishes static HTML/CSS/JS directly from the repository.

The site will normally be available at:
`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

For a user/organization site, use a repository named:
`YOUR-GITHUB-USERNAME.github.io`

## Important
GitHub Pages websites are public on the internet. Do not put passwords, private financial data, customer personal data, or confidential documents in this repository.
